## 1. 产品概述

### 1.1 产品背景

本项目是一款基于 PySide2 的桌面数据库管理应用程序，专为 InterSystems Cache/IRIS 数据库设计。提供可视化的数据库连接管理、SQL查询执行、数据导出和日志管理等功能。

### 1.2 产品目标

- 提供直观的数据库连接配置和管理界面
- 支持高效的SQL查询和数据浏览
- 保障数据库连接的安全性（密码加密、SQL注入防护）
- 提供完整的数据导出功能（CSV/Excel/TXT）
- 实现结构化的日志管理和查看

### 1.3 目标用户

- 数据库管理员
- 软件开发人员
- 数据分析师

### 1.4 运行环境

- **操作系统**: Windows 7/10/11
- **Python版本**: 3.8+
- **数据库**: InterSystems Cache / IRIS

### 2.2 功能详细说明

#### 2.2.1 数据库连接配置流程

```
1. 用户打开连接配置对话框
2. 选择数据库类型（Cache/IRIS）
3. 填写连接参数（服务器、端口、命名空间、用户名、密码）
4. 点击"测试连接"验证配置
5. 可选择"保存配置"存储到配置文件
6. 点击"连接"建立数据库连接
```

#### 2.2.2 SQL查询流程

```
1. 用户打开SQL查询对话框
2. 系统自动加载数据库对象树
3. 用户在编辑器中输入SQL语句
4. 系统自动进行语法高亮
5. 用户点击"执行"运行查询
6. 系统在结果表格中显示数据
7. 用户可使用分页控件浏览结果
8. 用户可选择"导出"保存数据
```

#### 2.2.3 日志查看流程

```
1. 用户打开日志对话框
2. 系统加载日志文件列表
3. 用户选择日志文件
4. 系统显示日志内容（带行号）
5. 用户可在搜索框输入关键词
6. 系统高亮显示匹配内容
7. 用户可使用导航按钮跳转
```

## 8. 安全需求详细说明

### 8.1 密码加密方案

- **算法**: PBKDF2-SHA256
- **迭代次数**: 100000
- **盐值**: 随机16字节
- **存储格式**: `salt:encrypted_password` (Base64编码)

### 8.2 SQL注入防护

1. **参数化查询**: 所有SQL语句使用参数化查询
2. **输入清理**: 移除危险字符（分号、注释符号等）
3. **关键字检测**: 检测危险的SQL关键字（DROP、DELETE等）
4. **权限控制**: 建议使用只读用户进行查询操作

### 8.3 危险SQL关键字列表

```python
DANGEROUS_KEYWORDS = [
    'DROP', 'DELETE', 'TRUNCATE', 'ALTER', 'GRANT',
    'REVOKE', 'EXEC', 'EXECUTE', 'SP_', 'XP_'
]
```
