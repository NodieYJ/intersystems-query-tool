## 📋 使用指南

### 1. 查询历史功能

```
1. 执行SQL查询
2. 点击"历史"按钮
3. 在对话框中查看、搜索历史记录
4. 双击记录可复用SQL
```

### 2. 日志查看功能

```
1. 点击菜单"设置" -> "日志"
2. 选择日志文件
3. 使用搜索框搜索关键词
4. 日志级别自动高亮显示
5. 点击"导出当前日志"导出文件
```

### 3. 数据分析功能

```
1. 点击菜单"查询统计" -> "数据分析"
2. 选择数据源（SQL结果或文件）
3. 加载数据后查看预览
4. 点击"计算统计分析"查看统计
5. 在图表页配置并绘制图表
6. 点击"导出分析报告"导出Excel
```
