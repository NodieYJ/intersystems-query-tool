## 1. 产品概述

### 1.1 项目背景

本项目是一款基于 PySide2 的桌面数据库管理应用程序，专为 InterSystems Cache/IRIS 数据库设计。产品旨在整合数据库查询、多源数据融合、交互式分析与可视化能力，打造一个"个人数据分析工作站"，终结用户在多个工具间频繁切换的繁琐流程，显著提升数据工作的效率与体验。

### 1.2 产品愿景

成为 InterSystems 数据库生态中最易用、最高效的轻量级桌面分析工具，让数据查询和分析工作变得简单、直观、专业。

### 1.3 产品核心价值

1. **一站式数据操作**：提供流畅的数据库查询体验，并集成文件数据分析能力，打破数据源壁垒
2. **提升分析效率**：通过直观的 GUI 和交互式图表，降低数据探索与可视化的技术门槛
3. **保障技术兼容**：确保在 Windows 7 及 Python 3.10 环境下稳定运行，并通过打包为独立可执行文件简化部署
4. **建立专业工具标准**：通过语法高亮、多标签页、历史记录等专业功能，树立轻量级客户端工具的体验标杆

### 1.4 产品目标

| 目标类型 | 具体目标 | 优先级 |
|----------|----------|--------|
| 功能目标 | 完成数据库查询、数据可视化、报告导出三大核心功能 | 高 |
| 性能目标 | 冷启动≤5秒，简单查询渲染≤2秒 | 高 |
| 体验目标 | 用户无需手册即可完成基本操作 | 中 |
| 部署目标 | 打包为单个可执行文件，在纯净Win7环境可运行 | 高 |

### 1.5 运行环境

| 环境项 | 要求 |
|--------|------|
| 操作系统 | Windows 7 SP1 / Windows 10 / Windows 11 |
| Python版本 | Python 3.8+ (推荐 3.10.x) |
| 数据库 | InterSystems Cache 2018.1+ / IRIS 2021.1+ |
| 内存 | ≥ 4GB RAM |
| 硬盘 | ≥ 500MB 可用空间 |

## 2. 目标用户与使用场景

### 2.1 目标用户画像

#### 2.1.1 数据库开发工程师

- **核心需求**：流畅的 SQL 编辑、调试和历史复用
- **使用频率**：每日使用
- **技能水平**：精通SQL，熟悉数据库管理
- **痛点**：现有工具功能单一，需要在多个软件间切换

#### 2.1.2 数据分析师/业务分析师

- **核心需求**：易用的数据导入、直观的图表生成和一键报告导出
- **使用频率**：每周多次
- **技能水平**：懂基础SQL，擅长数据分析
- **痛点**：技术门槛高，可视化工具学习成本大

#### 2.1.3 系统运维人员

- **核心需求**：稳定的连接、快速查询和报告生成能力
- **使用频率**：按需使用
- **技能水平**：了解基础数据库操作
- **痛点**：需要快速获取数据状态，现有工具操作复杂

#### 2.1.4 数据库管理员

- **核心需求**：多连接管理、日志监控、性能诊断
- **使用频率**：每日使用
- **技能水平**：精通数据库管理和调优
- **痛点**：缺乏轻量级管理工具

### 2.2 典型使用场景

#### 场景一：数据库查询与导出

```
用户启动工具 → 配置连接至IRIS/Cache数据库 → 在查询页编写/执行SQL 
→ 查看结果 → 直接导出原始数据Excel → 任务完成
```

#### 场景二：数据库查询与深度分析

```
用户启动工具 → 配置连接 → 编写/执行SQL → 将结果发送至分析页 
→ 查看基础统计摘要 → 配置图表类型与数据映射 
→ 交互式图表渲染与探索 → 导出分析报告或图表 → 任务完成
```

#### 场景三：本地文件分析

```
用户启动工具 → 在分析页选择本地CSV/Excel/TXT文件 
→ 文件加载与数据预览 → 查看基础统计摘要 
→ 配置图表类型与数据映射 → 交互式图表渲染 
→ 导出图表或Excel报告 → 任务完成
```

#### 场景四：日志监控与排查

```
用户启动工具 → 打开日志查看器 → 选择日志文件 
→ 搜索关键词定位问题 → 查看上下文分析原因 
→ 导出相关日志片段 → 任务完成
```

#### 3.2.2 功能详细说明

**连接管理 (CON-001)**

- 支持配置服务器地址、端口、命名空间、用户名、密码
- 提供连接测试功能，实时反馈连接状态
- 支持保存多组连接配置，便于快速切换
- 配置文件中的密码需加密存储

**SQL编辑器 (SQL-001)**

- 支持多标签页，可同时编辑多个SQL语句
- 提供SQL语法高亮（关键字、字符串、注释等）
- 支持快捷键执行（F5或Ctrl+Enter）
- 显示执行状态和耗时信息

**查询历史记录 (SQL-008)**

- 自动记录每次执行的SQL语句（时间戳、执行耗时）
- 支持按关键词搜索历史记录
- 双击历史记录可直接加载到编辑器
- 支持清空历史记录

**查询导出 (SQL-009)**

- 支持导出格式：CSV、Excel（.xlsx）、TXT
- 支持导出当前页或全部结果
- 支持自定义文件名和导出路径

### 3.3 模块三：数据分析与可视化

#### 3.3.1 功能清单

| 功能ID | 功能名称 | 详细描述与量化要求 | 输入 | 输出 | 优先级 |
|--------|----------|-------------------|------|------|--------|
| ANAL-001 | 多源数据加载 | 支持从当前SQL结果或本地文件（CSV/Excel/TXT，≤200MB）加载，并提供数据预览 | SQL结果集或文件路径 | Pandas DataFrame、预览信息 | Should |
| ANAL-002 | 数据预览 | 显示数据前N行（默认100行），显示数据类型和基本信息 | DataFrame | 数据预览表格 | Should |
| ANAL-003 | 基础统计分析 | 自动计算数值型字段的计数、均值、标准差、分位数等，并以表格展示 | DataFrame | 统计指标表格 | Should |
| ANAL-004 | 数据筛选 | 支持按条件筛选数据、排序 | 用户选择 | 筛选后数据 | Could |
| ANAL-005 | 交互式图表绘制 | 支持折线图、柱状图、散点图、饼图。配置变更后图表重绘时间<1秒，支持缩放平移 | DataFrame、用户配置 | 实时更新的图表 | Should |
| ANAL-006 | 图表配置 | 支持选择X/Y轴字段、图表类型、颜色主题、标题等 | 用户选择 | 图表配置参数 | Should |
| ANAL-007 | 图表导出 | 导出图表为PNG图片 | 图表对象 | .png文件 | Should |
| ANAL-008 | 分析报告导出 | 导出包含"原始数据"、"数据概览"、"分析图表"三部分的Excel报告 | DataFrame、统计表、图表 | .xlsx文件 | Should |

#### 3.3.2 功能详细说明

**多源数据加载 (ANAL-001)**

- 支持从当前SQL查询结果一键发送到分析模块
- 支持加载本地CSV、Excel（.xls/.xlsx）、TXT文件
- 文件大小限制：≤200MB
- 自动检测文件编码格式
- 显示数据加载进度

**基础统计分析 (ANAL-003)**

- 自动识别数值型字段
- 计算指标：计数、均值、标准差、最小值、25%分位数、中位数、75%分位数、最大值
- 以表格形式清晰展示统计结果
- 支持复制统计结果

**交互式图表绘制 (ANAL-005)**

- 支持的图表类型：
  - 折线图（适合趋势分析）
  - 柱状图（适合分类对比）
  - 散点图（适合相关性分析）
  - 饼图（适合占比分析）
- 交互功能：
  - 鼠标滚轮缩放
  - 拖拽平移
  - 悬停显示数值
- 性能要求：配置变更后图表重绘时间<1秒

**分析报告导出 (ANAL-008)**

- Excel报告包含三个工作表：
  1. 原始数据：完整的查询结果或导入数据
  2. 数据概览：基础统计分析结果
  3. 分析图表：导出的图表图片

- **算法**: PBKDF2-SHA256
- **迭代次数**: 100000
- **盐值**: 随机16字节
- **存储格式**: `salt:encrypted_password` (Base64编码)

**加密流程**:
```
1. 生成随机16字节盐值
2. 使用PBKDF2-SHA256算法，迭代100000次
3. 将盐值和加密后的密码拼接
4. 使用Base64编码存储
```

### 8.2 SQL注入防护

1. **参数化查询**: 所有SQL语句使用参数化查询，禁止字符串拼接
2. **输入清理**: 移除危险字符（分号、注释符号等）
3. **关键字检测**: 检测危险的SQL关键字
4. **权限控制**: 建议使用只读用户进行查询操作

### 8.3 危险SQL关键字列表

```python
DANGEROUS_KEYWORDS = [
    'DROP', 'DELETE', 'TRUNCATE', 'ALTER', 'GRANT',
    'REVOKE', 'EXEC', 'EXECUTE', 'SP_', 'XP_',
    'UNION', 'INSERT', 'UPDATE'
]
```
