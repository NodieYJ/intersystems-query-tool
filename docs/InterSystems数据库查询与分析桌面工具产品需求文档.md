## 1. 产品概述

### 1.1 项目背景

为满足 InterSystems Cache/IRIS 数据库用户在 Windows 7 环境下对轻量级、一体化数据工具的需求，特立项开发本桌面应用程序。产品旨在整合数据库查询、多源数据融合、交互式分析与可视化能力，打造一个"个人数据分析工作站"，终结用户在多个工具间频繁切换的繁琐流程，显著提升数据工作的效率与体验。

### 1.2 产品愿景

成为 InterSystems 数据库生态中最易用、最高效的轻量级桌面分析工具，让数据查询和分析工作变得简单、直观、专业。

### 1.3 产品核心价值

1. **一站式数据操作**：提供流畅的数据库查询体验，并集成文件数据分析能力，打破数据源壁垒
2. **提升分析效率**：通过直观的 GUI 和交互式图表，降低数据探索与可视化的技术门槛
3. **保障技术兼容**：确保在 Windows 7 及 Python 3.10 环境下稳定运行，并通过打包为独立可执行文件简化部署
4. **建立专业工具标准**：通过语法高亮、多标签页、历史记录等专业功能，树立轻量级客户端工具的体验标杆

### 1.4 产品目标

| 目标类型 | 具体目标 | 优先级 |
|----------|----------|--------|
| 功能目标 | 完成数据库查询、数据可视化、报告导出三大核心功能 | 高 |
| 性能目标 | 冷启动≤5秒，简单查询渲染≤2秒 | 高 |
| 体验目标 | 用户无需手册即可完成基本操作 | 中 |
| 部署目标 | 打包为单个可执行文件，在纯净Win7环境可运行 | 高 |

## 2. 目标用户与使用场景

### 2.1 目标用户画像

#### 2.1.1 数据库开发工程师

- **核心需求**：流畅的 SQL 编辑、调试和历史复用
- **使用频率**：每日使用
- **技能水平**：精通SQL，熟悉数据库管理
- **痛点**：现有工具功能单一，需要在多个软件间切换

#### 2.1.2 数据分析师/业务分析师

- **核心需求**：易用的数据导入、直观的图表生成和一键报告导出
- **使用频率**：每周多次
- **技能水平**：懂基础SQL，擅长数据分析
- **痛点**：技术门槛高，可视化工具学习成本大

#### 2.1.3 系统运维人员

- **核心需求**：稳定的连接、快速查询和报告生成能力
- **使用频率**：按需使用
- **技能水平**：了解基础数据库操作
- **痛点**：需要快速获取数据状态，现有工具操作复杂

### 2.2 典型使用场景

#### 场景一：数据库查询与导出

```
用户启动工具 → 配置连接至IRIS/Cache数据库 → 在查询页编写/执行SQL 
→ 查看结果 → 直接导出原始数据Excel → 任务完成
```

#### 场景二：数据库查询与深度分析

```
用户启动工具 → 配置连接 → 编写/执行SQL → 将结果发送至分析页 
→ 查看基础统计摘要 → 配置图表类型与数据映射 
→ 交互式图表渲染与探索 → 导出分析报告或图表 → 任务完成
```

#### 场景三：本地文件分析

```
用户启动工具 → 在分析页选择本地CSV/Excel/TXT文件 
→ 文件加载与数据预览 → 查看基础统计摘要 
→ 配置图表类型与数据映射 → 交互式图表渲染 
→ 导出图表或Excel报告 → 任务完成
```

## 3. 功能需求

### 3.1 模块一：数据库连接与核心查询

#### 3.1.1 功能清单

| 功能ID | 功能名称 | 详细描述 | 输入 | 输出 | 优先级 |
|--------|----------|----------|------|------|--------|
| CON-001 | 连接管理 | 图形化配置连接参数，支持测试、保存多组配置 | 数据库连接参数 | 连接状态 | Must |
| CON-002 | 数据库类型选择 | 支持InterSystems IRIS和Cache两种类型 | 用户选择 | 数据库类型配置 | Must |
| SQL-001 | SQL编辑器 | 多标签页编辑器，支持语法高亮、快捷键执行 | SQL语句、用户操作 | 执行状态、查询结果集 | Must |
| SQL-002 | 查询结果展示 | 表格展示结果，支持选中复制文本、列宽调整 | 查询结果集 | 界面表格、剪贴板文本 | Must |
| SQL-003 | 查询历史记录 | 自动记录SQL执行历史，支持搜索和双击复用 | 历史SQL记录 | 加载至编辑器的SQL | Should |
| SQL-004 | 查询导出 | 将查询结果直接导出为Excel格式 | 查询结果集 | .xlsx文件 | Must |

#### 3.1.2 功能详细说明

**连接管理 (CON-001)**

- 支持配置服务器地址、端口、命名空间、用户名、密码
- 提供连接测试功能，实时反馈连接状态
- 支持保存多组连接配置，便于快速切换
- 配置文件中的密码需加密存储

**SQL编辑器 (SQL-001)**

- 支持多标签页，可同时编辑多个SQL语句
- 提供SQL语法高亮（关键字、字符串、注释等）
- 支持快捷键执行（如F5或Ctrl+Enter）
- 显示执行状态和耗时信息

**查询历史记录 (SQL-003)**

- 自动记录每次执行的SQL语句
- 支持按关键词搜索历史记录
- 双击历史记录可直接加载到编辑器
- 支持清空历史记录

### 3.2 模块二：数据分析与可视化

#### 3.2.1 功能清单

| 功能ID | 功能名称 | 详细描述与量化要求 | 输入 | 输出 | 优先级 |
|--------|----------|-------------------|------|------|--------|
| DATAL-001 | 多源数据加载 | 支持从当前SQL结果或本地文件（CSV/Excel/TXT，≤200MB）加载，并提供数据预览 | SQL结果集或文件路径 | Pandas DataFrame、预览信息 | Should |
| DATAL-002 | 数据预览 | 显示数据前N行（默认100行），显示数据类型和基本信息 | DataFrame | 数据预览表格 | Should |
| STAT-001 | 基础统计分析 | 自动计算数值型字段的计数、均值、标准差、分位数等，并以表格展示 | DataFrame | 统计指标表格 | Should |
| CHART-001 | 交互式图表绘制 | 支持折线图、柱状图、散点图、饼图。配置变更后图表重绘时间<1秒，支持缩放平移 | DataFrame、用户配置 | 实时更新的PyQtGraph图表 | Should |
| CHART-002 | 图表配置 | 支持选择X/Y轴字段、图表类型、颜色主题、标题等 | 用户选择 | 图表配置参数 | Should |
| EXPORT-001 | 分析报告导出 | 可导出图表为PNG，或导出包含"原始数据"、"数据概览"、"分析图表"三部分的Excel报告 | DataFrame、统计表、图表 | .xlsx文件或.png图片 | Should |

#### 3.2.2 功能详细说明

**多源数据加载 (DATAL-001)**

- 支持从当前SQL查询结果一键发送到分析模块
- 支持加载本地CSV、Excel（.xls/.xlsx）、TXT文件
- 文件大小限制：≤200MB
- 自动检测文件编码格式
- 显示数据加载进度

**基础统计分析 (STAT-001)**

- 自动识别数值型字段
- 计算指标：计数、均值、标准差、最小值、25%分位数、中位数、75%分位数、最大值
- 以表格形式清晰展示统计结果
- 支持复制统计结果

**交互式图表绘制 (CHART-001)**

- 支持的图表类型：
  - 折线图（适合趋势分析）
  - 柱状图（适合分类对比）
  - 散点图（适合相关性分析）
  - 饼图（适合占比分析）
- 交互功能：
  - 鼠标滚轮缩放
  - 拖拽平移
  - 悬停显示数值
- 性能要求：配置变更后图表重绘时间<1秒

**分析报告导出 (EXPORT-001)**

- Excel报告包含三个工作表：
  1. 原始数据：完整的查询结果或导入数据
  2. 数据概览：基础统计分析结果
  3. 分析图表：导出的图表图片
- 图表导出支持PNG格式
- 支持自定义报告文件名

### 6.1 里程碑规划 (MoSCoW法则)

#### M (Must Have) - 第一期：V1.0 基础版

**目标**：完成核心查询、原始数据导出及基础UI

| 功能模块 | 具体功能 | 工作量(人天) |
|----------|----------|--------------|
| 数据库连接 | 连接配置、测试、保存 | 3 |
| SQL编辑器 | 多标签页、执行、结果展示 | 5 |
| 数据导出 | Excel导出功能 | 2 |
| UI框架 | 主窗口、菜单栏、状态栏 | 3 |
| 合计 | | 13 |

**交付物**：
- 可连接IRIS/Cache数据库
- 可执行SQL并查看结果
- 可导出查询结果到Excel

#### S (Should Have) - 第二期：V1.2 完整版

**目标**：完成查询历史、完整的数据分析与可视化模块

| 功能模块 | 具体功能 | 工作量(人天) |
|----------|----------|--------------|
| SQL编辑器增强 | 语法高亮、查询历史 | 3 |
| 数据加载 | 文件加载、SQL结果发送 | 2 |
| 统计分析 | 基础统计指标计算 | 2 |
| 可视化 | 图表绘制、交互功能 | 5 |
| 报告导出 | 图表导出、Excel报告 | 3 |
| 合计 | | 15 |

**交付物**：
- 完整的SQL编辑器（含语法高亮、历史记录）
- 数据分析模块（加载、统计、可视化）
- 报告导出功能

#### C (Could Have) - 未来迭代

- SQL自动补全功能
- 图表模板库
- 定时任务和自动化
- 数据库对象管理（表结构查看）
- 数据对比功能

#### W (Won't Have) - 不在范围内

- 多用户协作功能
- 复杂ETL设计器
- 数据库管理功能（用户管理、备份等）
- Web版或移动端
