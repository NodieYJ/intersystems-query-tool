## 1. 简介

### 1.1 产品概述

InterSystems 数据库查询与分析工具是一款功能强大的桌面应用程序，专为 InterSystems IRIS/Cache 数据库设计。主要功能包括：

- **数据库连接管理** - 支持多配置连接
- **SQL 查询** - 语法高亮、自动补全
- **查询历史** - 记录、搜索、复用历史查询
- **日志管理** - 查看、搜索、导出日志文件
- **数据分析** - 统计、图表、报告导出

### 1.2 主要特性

| 特性 | 描述 |
|------|------|
| 多数据库支持 | 支持 InterSystems IRIS、Cache |
| 智能查询 | 语法高亮、自动补全 |
| 历史记录 | 保存和搜索历史查询 |
| 数据导出 | 支持 CSV、Excel 格式 |
| 图表分析 | 柱状图、折线图、散点图 |
| 日志查看 | 搜索、高亮、大文件支持 |

## 3. 安装指南

### 3.1 方式一：使用 venv（推荐）

```bash

venv\Scripts\activate
```

## 4. 快速入门

### 4.1 首次启动

1. 运行应用程序：`python src/main.py`
2. 首次启动会自动创建配置文件
3. 显示主窗口界面

### 4.2 连接数据库

1. 点击菜单栏 **文件 → 新建连接**
2. 或点击工具栏 **连接** 图标
3. 填写数据库连接信息
4. 点击 **测试连接** 验证配置
5. 点击 **保存** 保存配置
6. 点击 **连接** 连接到数据库

### 4.3 执行查询

1. 在 SQL 编辑器中输入查询语句
2. 点击 **执行** 按钮（或按 F5）
3. 查看结果表格
4. 导出结果（如需要）

## 6. 数据库连接

### 6.1 新建连接

1. **打开连接对话框**
   - 菜单：文件 → 新建连接
   - 工具栏：点击连接图标

2. **填写连接信息**

| 字段 | 说明 | 示例 |
|------|------|------|
| 连接名称 | 自定义名称 | 生产环境 |
| 服务器 | IP 或主机名 | localhost |
| 端口 | 端口号 | 51773 |
| 数据库 | 数据库名称 | USER |
| 用户名 | 用户名 | admin |
| 密码 | 密码 | ******** |
| 命名空间 | 命名空间 | USER |

3. **保存连接**
   - 点击"测试连接"验证
   - 点击"保存"保存配置

### 6.2 管理连接

- **编辑连接**: 选择连接，点击编辑
- **删除连接**: 选择连接，点击删除
- **复制连接**: 右键 → 复制

### 6.3 连接状态

状态栏显示当前连接状态：
- 🟢 已连接
- 🔴 未连接
- 🟡 正在连接...

## 13. 故障排除

### 13.1 常见问题

#### Q1: 连接数据库失败

**可能原因**：
1. 数据库服务未启动
2. 连接信息错误
3. 网络问题
4. 防火墙阻止

**解决方案**：
1. 确认数据库服务运行
2. 检查连接信息（主机、端口、用户名、密码）
3. 检查网络连通性
4. 暂时关闭防火墙测试

#### Q2: SQL 执行超时

**可能原因**：
1. 查询复杂度高
2. 数据量过大
3. 数据库服务器负载高

**解决方案**：
1. 优化查询语句
2. 添加 LIMIT 限制返回行数
3. 在非高峰时段执行

#### Q3: 导出文件失败

**可能原因**：
1. 磁盘空间不足
2. 文件权限问题
3. 文件被其他程序占用

**解决方案**：
1. 检查磁盘空间
2. 检查文件权限
3. 关闭占用文件的程序

#### Q4: 界面显示异常

**可能原因**：
1. DPI 设置问题
2. 显卡驱动问题
3. 分辨率不兼容

**解决方案**：
1. 调整缩放比例设置
2. 更新显卡驱动
3. 尝试其他分辨率

### 13.2 错误日志

**日志位置**：
- 应用日志：`pywindows.log`
- 错误日志：`~/pywindows_error.log`

**查看方式**：
1. 打开日志查看器（工具 → 日志查看器）
2. 或直接查看日志文件

### 13.3 重置配置

**重置步骤**：
1. 关闭应用程序
2. 删除配置文件 `config.json`
3. 重启应用程序
4. 重新配置

## 14. 常见问题

### 14.1 一般问题

**Q: 是否支持其他数据库？**
A: 当前版本主要支持 InterSystems IRIS/Cache。理论上支持 ODBC/JDBC 连接的其他数据库。

**Q: 是否支持多语言？**
A: 当前版本支持简体中文。英文版本正在开发中。

**Q: 是否免费？**
A: 是的，这是一个开源免费项目。

### 14.2 功能问题

**Q: 可以同时打开多个连接吗？**
A: 当前版本支持多标签页编辑，但同时只能有一个活动连接。

**Q: 最大支持多大的数据导出？**
A: 理论上无限制，受限于系统内存。建议大结果集使用 LIMIT 分批导出。

**Q: 支持定时执行吗？**
A: 当前版本不支持定时任务功能。

### 14.3 技术问题

**Q: Python 版本要求？**
A: 需要 Python 3.8.x

**Q: 支持 macOS 或 Linux 吗？**
A: 当前版本主要测试 Windows。macOS 和 Linux 理论上支持，但可能有兼容性问题。

**Q: 如何更新到新版本？**
A: 覆盖安装即可，注意备份配置文件。
