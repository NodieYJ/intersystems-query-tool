### 1.2 技术栈

| 组件 | 技术选型 | 原因 |
|------|---------|------|
| **桌面UI** | PySide2 | 现有技术栈，Windows兼容 |
| **业务逻辑** | Python 3.9+ | 现有技术栈 |
| **并发模型** | asyncio + multiprocessing | Python最佳实践，5000+并发 |
| **HTTP/2** | aiohttp | Python异步HTTP客户端/服务器 |
| **WebSocket** | aiohttp.webSocket | 原生支持 |
| **序列化** | MessagePack + JSON | 高性能+可读 |
| **认证** | JWT Token | 无状态、可扩展 |
| **配置** | JSON + 环境变量 | 简单、灵活 |
| **测试** | pytest + pytest-asyncio | 异步测试支持 |
| **部署** | Windows服务 + 系统托盘 | Windows原生体验 |
