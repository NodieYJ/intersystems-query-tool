# 模型策略配置

**生效日期**: 2026-02-14  
**策略**: 自动选择 + 手动干预

---

## 自动选择规则（方案1）

作为Orchestrator，我根据任务类型自动选择模型类别：

### 任务类别映射

| 任务类型 | 类别 | 模型倾向 | 关键词 |
|---------|------|---------|--------|
| **代码重构/实现** | `ultrabrain` | Llama3-70B | 重构、拆分、实现、优化、SQL |
| **架构设计** | `deep` | Llama3-70B | 架构、设计、模式、依赖 |
| **代码审查** | `ultrabrain` | Llama3-70B | 审查、分析、检查 |
| **UI/UX设计** | `visual-engineering` | GLM/Llama3 | 界面、样式、设计 |
| **文档编写** | `writing` | GLM-4.7-Free | 文档、README、说明、注释 |
| **快速修复** | `quick` | GLM-4.7-Free | 修复、简单、快速 |
| **配置/检查** | `quick` | GLM-4.7-Free | 配置、查看、检查、验证 |

### 决策流程

```
用户请求
    ↓
分析任务类型
    ↓
选择类别 → 自动匹配最优模型
    ↓
执行任务
```

## 手动干预规则（方案2）

用户可以随时要求切换模型：

### 切换命令

```bash
# 切换到指定模型
/model nim-llama3-70b    # 代码专用
/model nim-llama3-8b     # 快速代码
/model glm-4.7-free      # 中文通用
/model nim-mixtral-8x22b # 复杂推理

# 查看当前模型
/model

# 列出所有模型
opencode models list
```

### 自然语言切换

用户也可以说：
- "用 Llama3 试试"
- "切换到 GLM"
- "换个模型"
- "用 NIM 的模型"

## 当前项目策略（PyWindows）

### 默认策略
- **默认模型**: GLM-4.7-Free
- **代码任务**: 自动使用 ultrabrain → Llama3-70B
- **文档任务**: 自动使用 writing → GLM-4.7-Free

### 场景示例

**场景1: 架构重构**
```
用户: 拆分 main_window.py
系统: [自动] 类别=ultrabrain → Llama3-70B
用户: 用 GLM 分析一下
系统: [手动] 切换到 GLM-4.7-Free
用户: 还是 Llama3 好
系统: [手动] 切回 Llama3-70B 执行
```

**场景2: 代码 + 文档**
```
用户: 实现 SQL 补全功能
系统: [自动] 类别=ultrabrain → Llama3-70B (写代码)
用户: 写一下使用文档
系统: [自动] 类别=writing → GLM-4.7-Free (写文档)
```
