# 项目归档目录

## 说明

此目录用于存放项目中不再使用但具有历史价值或参考价值的文件。

## 子目录结构

```
archive/
├── demos/          # 演示和原型文件
├── tools/          # 工具脚本
├── tests/          # 归档的测试文件
└── README.md       # 本文件
```

## 各目录说明

### demos/
存放UI演示、原型设计等探索性文件：
- 样式演示文件（style_demo*.py）
- 表单设计器原型（form_designer*.py）

### tools/
存放维护和修复用的临时工具脚本：
- LSP问题修复脚本
- 代码格式化工具
- 批量替换工具

### tests/
存放从根目录移出的临时测试文件：
- 开发调试脚本
- 探索性测试
- 已整合到正式测试的临时文件

## 管理策略

1. **定期审查**：每隔一段时间检查此目录，删除确定不再需要的文件
2. **保留价值**：只保留有参考价值或可能复用的文件
3. **文档说明**：每个子目录都有README说明文件用途
4. **不纳入版本控制**：可以考虑在 `.gitignore` 中忽略此目录

## 清理建议

如果确定以下文件不再需要，可以安全删除：

- **6个月后**：查看是否有人访问过这些文件
- **发布后**：项目稳定运行一个版本后
- **重构后**：如果代码已完全重写

## 注意事项

- 归档文件不再维护，可能与当前代码不兼容
- 不要直接在生产环境使用归档文件
- 使用前先阅读各子目录的README说明
