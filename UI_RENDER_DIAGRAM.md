# 🎨 现代化扁平设计 UI 界面渲染图

> 基于 UI/UX Pro Max 设计系统为 PySide2 数据查询工具生成的现代化扁平设计语言

---

## 📐 设计概述

### 设计方向
- **风格**: Flat Design + Soft UI Evolution 混合
- **色彩**: 专业蓝色系 + 琥珀强调色
- **字体**: Segoe UI / Microsoft YaHei（中文优化）
- **圆角**: 6-8px（现代柔和）
- **阴影**: 极浅层次阴影（符合扁平化）

### 核心特征
- ✅ 无渐变（纯平色）
- ✅ 极简阴影（仅用于层次区分）
- ✅ 清晰的视觉层级
- ✅ 充足留白
- ✅ 高对比度文字
- ✅ 平滑微交互动画

```

│  -- 查询活跃用户                                               │

│      u.name,                                                  │
│      u.email,                                                 │
│      u.status,                                                │
│      u.created_at                                             │
│  FROM users u                                                 │
│  WHERE u.status = 'active'                                    │
│    AND u.created_at >= '2024-01-01'                           │
│  ORDER BY u.created_at DESC                                   │
│  LIMIT 100;                                                   │

│                                                                 │
│                                                                 │
```

```python
app.setStyleSheet(get_complete_style())
```
